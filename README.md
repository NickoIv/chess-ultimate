# Chess Ultimate Academy

**Играть онлайн:** https://nickoiv.github.io/chess-ultimate/

Профессиональная офлайн-ориентированная шахматная игра и интерактивная Академия. Это актуальная веб-сборка от 22 ноября 2026 года. Доступна на компьютере и мобильных устройствах.

## Возможности

- Партии с компьютером и вдвоём на одном устройстве; контроль времени или без часов.
- Семь относительных уровней сложности без неподтверждённых рейтингов Эло.
- Интерактивная Академия: 55 уроков и 115 упражнений с многоступенчатыми подсказками.
- Анимации ходов и взятий, выделение последних ходов, повтор движения.
- Анализ сыгранных партий, задачи из ошибок, сохранение прогресса.
- Резервная копия данных в JSON, импорт и экспорт PGN.
- Приложение работает без обязательного аккаунта; PWA может работать офлайн после установки.

## Использование

Главный файл — `index.html`. Для публичного сайта используется GitHub Pages, который публикует только `index.html`, `sw.js`, `manifest.webmanifest` и `icon.svg`. Унаследованные файлы старых шахматных экспериментов в истории репозитория не используются онлайн-версией.

### Сохранность данных

Партии, настройки и прогресс хранятся в браузере конкретного устройства. При смене браузера или очистке данных без резервной копии они не перенесутся автоматически. Перед переустановкой используйте экспорт JSON.

### Статус

Онлайн-сборка опубликована для использования и проверки. Полная профессиональная оценка образовательного содержания, производительности на реальном iPhone Safari и коммерческая сертификация ещё не завершены.

## Развёртывание

Автоматическая публикация через `.github/workflows/pages.yml` после изменений веб-файлов в ветке `main`. Отдельный хостинг Cloudflare не используется.
